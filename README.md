# PSP · Tema 1 · Multiprocesos

Web interactiva para estudiar el Tema 1 de **Programación de Servicios y Procesos** (2.º DAM, IES Rafael Alberti).

## 👉 [Abrir la web](https://pmaliagil1.github.io/psp-tema1-multiprocesos/)

https://pmaliagil1.github.io/psp-tema1-multiprocesos/

## Qué incluye

- Teoría de los 6 bloques: programa, proceso, servicio e hilo · concurrente, paralela y distribuida · estados de un proceso · planificación de la CPU · procesos en Java · comunicar y controlar procesos.
- Tests con corrección al momento y explicación de cada respuesta.
- Ejercicios de código Java: rellenar huecos y escribir desde cero con comprobación de piezas.
- Simulador de diagramas de Gantt (FCFS, SJF y Round Robin con llegadas) con modo práctica.
- Comprobador de transiciones entre estados.
- Lista de requisitos de la práctica final (el lanzador de tareas).

Todo funciona en el navegador, sin instalar nada. El progreso se guarda en el navegador que uses.
